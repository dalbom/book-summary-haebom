# 책 요약해봄

긴 책을 한국어 요약본 `.docx` 파일로 만들어 주는 [Claude Code](https://claude.com/claude-code) 스킬입니다.

- 우리 아이 수준에 맞춰서 분량과 어휘 조절
- 페이지 수는 원하는 만큼 (예: "40쪽 정도로")
- 어려운 단어 사전, 토론 질문 자동 첨부
- 원하면 삽화까지 (별도 플러그인 설치 시 docx에 자동 삽입)

## ⚠️ 시작하기 전에

- 이 저장소는 어떤 책의 요약본도 직접 배포하지 않습니다. 사용자 본인의 컴퓨터에서 `.docx` 파일을 만드는 도구일 뿐입니다.
- 요약 대상은 본인이 적법하게 구입했거나 권리를 보유한 책으로 제한해 주세요. 저작권자 허락 없는 배포·재가공·상업적 이용은 저작권법 위반입니다.
- 이 도구로 만든 파일과 관련된 저작권 침해, 명예훼손, 기타 법적·윤리적 문제에 대해 저장소 작성자는 책임을 지지 않습니다. 사용 여부와 결과물 활용에 대한 책임은 전적으로 사용자에게 있습니다.

## 설치

먼저 [Claude Code](https://claude.com/claude-code)가 깔려 있어야 합니다. 그 다음 Claude에게 이렇게 말씀하세요:

> "https://github.com/dalbom/book-summary-haebom 저장소를 `~/.claude/skills/book-summary-haebom` 에 설치해줘."

Claude가 알아서 받아 옵니다.

## 사용

자연어로 부탁하면 됩니다.

**예 1.**
> "『어린 왕자』를 초등 저학년용으로 25쪽 분량으로 요약해줘."

**예 2.**
> "엄마가 어렸을 때 좋아했던 『빨간 머리 앤』을 우리 딸한테 읽어 주고 싶어. 친근한 말투로 40쪽 정도, 삽화 5장 넣어서. 1990년대 한국 동화책 느낌으로."

**예 3.**
> "『노인과 바다』 청소년용 50쪽 요약본. 원작 분위기는 살리되 폭력 묘사는 순화해줘."

Claude가 몇 가지 짧은 질문을 합니다 (대상 연령, 말투, 민감 장면 처리 등). 답변에 따라 요약본을 만들어 드립니다.

완성된 파일은 작업 폴더의 `books/{책 제목}/` 아래에 저장됩니다.
예: `books/어린왕자/어린왕자_요약.docx`
